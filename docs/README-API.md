# PQAI——面向专利专业人士的人工智能专利检索引擎
PQAI是一款由人工智能驱动的开源专利检索引擎，其支持以自然语言描述作为输入，基于语义匹配在专利数据库（目前只包括美国专利）和其他技术文献中检索出按相似度排序的对比文件列表进行展示。PQAI还支持将检索会话快照作为检索报告导出并分享给他人。

## PQAI适合谁？
- **发明人**。PQAI可以帮助发明人核查自己的发明构思是否已经存在相似专利，辅助判断发明构思是否独特。
- **专利代理师**。PQAI可以帮助专利代理师进行案前检索，以便判断技术方案的新颖性和创造性高度。
- **企业知识产权管理者**。PQAI可以帮助企业知识产权管理者快速判断技术方案的可专利性以及技术方案是否存在专利侵权风险。
