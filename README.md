# PQAI——基于语义匹配的AI专利检索引擎
>本项目为从专利代理师视角出发重构的PQAI中文技术文档作品集，Fork自[pqaidevteam/pqai](https://github.com/pqaidevteam/pqai)。

PQAI是一款开源的AI专利检索引擎。你只需输入自然语言描述的技术方案，系统便会基于语义匹配，从专利数据库（目前仅限美国专利）及其他技术文献中，返回按相似度排序的对比文件列表。PQAI还支持将检索会话快照作为检索报告导出并分享给他人。

## 快速上手
- 想快速体验？访问[PQAI官网](https://projectpq.ai/pqai-ai-patent-search-platform/)即可免费试用，无须注册。
- 想本地部署？参考[本地部署指南](docs/installation-guide.md)，基于 Ubuntu 22.04 的 Python 3.10 虚拟环境方式安装。

## 数据安全和隐私
>PQAI致力于帮助您探索现有技术，同时不损害您的隐私。
- **查询内容不记录**：一旦返回对比文件列表后，你的查询内容即从服务器删除，不会被追踪或记录。
- **传输加密**：你的所有检索请求均通过加密、安全的链路发送至PQAI服务器。
- **检索结果本地保存**：你收藏或保存的对比文件仅存储在本地浏览器中，不会上传至服务器。

## PQAI适合谁？
- **发明人**。  
  PQAI可以帮助发明人核查自己的发明构思是否已经存在相似专利，辅助判断发明构思是否独特。  
  *——可用于在提交技术交底书前的发明构思自检。*  

- **专利代理师**。  
  PQAI可以帮助专利代理师进行案前检索，以便判断技术方案的新颖性和创造性高度。  
  *——可用于正式撰写申请文件前的专利检索阶段。*  

- **企业知识产权管理者**。  
  PQAI可以帮助企业知识产权管理者快速判断技术方案的可专利性以及技术方案是否存在专利侵权风险。  
  *——可用于竞品专利监控或研发立项前的专利风险评估。*
